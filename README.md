# Sistema de Gestión de Entradas - MongoDB

## Descripción

Proyecto académico desarrollado durante la carrera de **Analista Programador** en INACAP.

El proyecto consiste en la implementación de una base de datos NoSQL en MongoDB para la administración de entradas a eventos, aplicando operaciones CRUD, manipulación de documentos y subdocumentos, consultas avanzadas y el framework de agregación.

## Objetivos

- Implementar una base de datos NoSQL utilizando MongoDB.
- Aplicar operaciones CRUD sobre documentos y subdocumentos.
- Gestionar información de clientes, eventos y ubicaciones.
- Realizar consultas avanzadas mediante operadores de MongoDB.

## Funcionalidades implementadas

- Creación de documentos.
- Lectura de información.
- Actualización de documentos y subdocumentos.
- Eliminación de documentos.
- Inserción y modificación de arreglos.
- Consultas utilizando operadores como:
  - `$regex`
  - `$sum`
  - `$avg`
  - `$round`
  - `$concat`
  - `$in`
  - `$all`
  - `$slice`
  - `$unwind`

## Tecnologías utilizadas

## Competencias desarrolladas

- Modelado de bases de datos NoSQL.
